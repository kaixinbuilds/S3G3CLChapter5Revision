选成 Text/Media 是最容易犯、也最难发现的错：游戏照样打得开，学生照样三关做到底，但分数一个都不会记录，教师后台永远是空的 —— 而这件事要等到你去看成绩时才会发现。这是作者自己踩过的坑，一个班的分数。

Choosing Text/Media is the easy mistake, and the hard one to notice: the game still opens, students still play all three levels through, but not a single mark is recorded and the gradebook stays empty — which you only discover when you go looking for the marks. The author made exactly this mistake, and it cost a class.

另外，Maximum Marks 要设成 36（开场画面显示的满分）。留在预设的 0，分数送出了也显示不出来。官方说明：SLS Teacher User Guide。

Also set Maximum Marks to 36, the number on the opening screen — left at the default 0, the score is sent but never shown. Official reference: SLS Teacher User Guide.
