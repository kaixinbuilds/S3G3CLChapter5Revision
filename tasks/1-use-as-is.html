🚀 原样拿去用

Use it as it is

题目一个字不改。走完这一页，你会有两样东西：一个自己的网址（发给学生就能玩），和一个能自动记分的 SLS 组件。

Change nothing. By the end of this page you will have two things: your own URL to hand students, and an SLS component that marks itself.

先决定你要哪一个

First, decide which one you need

只想让学生玩 —— 走 A 就够了。要分数进教师后台 —— 走 B。两个可以都做。

Just want students to play? A is enough. Want the marks in your gradebook? Do B. You can do both.

A

发一个网址给学生

Give students a link

  1. 开一个 GitHub 账号（免费，用学校邮箱就行）
  2. Create a free GitHub account
  3. 打开 这个 repo，右上角按 Fork —— 这是把整份复制到你自己的账号下
  4. Open the repo and press Fork to copy it into your own account
  5. 在你那一份里：Settings → Pages，Source 选 main，按 Save
  6. In your copy: Settings → Pages, set Source to main, Save
  7. 等一两分钟，网址会长成 https://你的账号.github.io/S3G3CLChapter5Revision/
  8. Wait a minute or two; your URL appears as https://your-name.github.io/S3G3CLChapter5Revision/

要学生直接进游戏，网址后面加上 game.html，跳过落地页。

To send students straight in, append game.html and skip the landing page.

这个版本的分数不会进教师后台 —— 学生只在自己画面上看到分数。要记分请走 B。

This build does not report to any gradebook; students only see their own score. For marks, do B.

B

上传 SLS，分数自动进教师后台

Upload to SLS so the marks land by themselves

上传前先读这一段 —— 组件类型选错，整个班的分数就没了。

Read this before you upload — pick the wrong component type and the whole class's marks are gone.

① 一定要选 Question → Free-Response → Interactive Response。选成 Text/Media，游戏照样打得开，学生照样三关做到底，画面上没有任何异样 —— 但分数一个都不会记录，你要等到去看成绩时才发现后台是空的。这是作者自己踩过的坑，一个班的分数。

① It must be Question → Free-Response → Interactive Response. With Text/Media the game still opens and students still play all three levels through, and nothing looks wrong — but not a single mark is recorded. You find out when you go looking for the marks and the gradebook is empty. The author made exactly this mistake, and it cost a class.

② Maximum Marks 要设成 36，留在预设的 0，分数送出了老师也看不到。

② Set Maximum Marks to 36. Left at the default 0, the score is sent but never shown.

官方说明：SLS Teacher User Guide — HTML5 Content Development

Official reference: SLS Teacher User Guide — HTML5 Content Development

⬇ unit5sls.zip 直接上传 SLS 📄 完整部署说明 Full guide
  1. 下载 unit5sls.zip（repo 最上层，已经压好了，不必自己压）
  2. Download unit5sls.zip from the top of the repo — already packaged
  3. SLS 课业里：Question → Free-Response → Interactive Response，上传 zip
  4. In your SLS lesson: Question → Free-Response → Interactive Response, then upload the zip
  5. Maximum Marks 设成 36（游戏开场画面显示的满分）
  6. Set Maximum Marks to 36 — the number on the game's opening screen
  7. 用学生视角做一关，到 Learning Progress 确认分数出现了
  8. Try one level as a student and check Learning Progress

上课前跟学生说两句

Two things to tell students

① 在 SLS 里作答，不要另开分页 —— 另开分页分数记录不到。游戏会先弹警告，但学生可以按「仍要继续」。

① Answer inside SLS, not in a new tab — otherwise the score cannot be recorded. The game warns first, but they can continue anyway.

② 三关做完会出现登顶画面，请自行截图交到 SLS —— 那是完成凭证，上面有姓名、班级、分数、用时与完成时刻。

② Screenshot the summit screen and submit it — it carries the name, class, marks, times and finish stamp, and is the completion evidence.

这两句话游戏开场画面上也写了，但课堂上再说一次比较保险。

Both appear on the game's opening screen too, but saying them aloud is safer.
