| # | 卡片（学生看到的文字） | 正确归属 |

**答后讲解**：作者引用名人的话来证明自己的论点，这叫**引用论证法**。

### 版面 3 · 反问句判断（4 分）

**指示（华文）**：反问句**答案就藏在问句里**，不需要回答。哪几句是？

**指示（English）**：A rhetorical question already contains its own answer. Which are which?

**格子**：「是反问句」　「不是反问句」

| # | 卡片（学生看到的文字） | 正确归属 |
|---|---|---|
| 3.1 | 不努力哪里会有收获？不学习怎么会有知识？ | 「是反问句」 |
| 3.2 | 凡事只要差不多就好了，何必太精明呢？ | 「是反问句」 |
| 3.3 | 人生就像一场盛大的演出，我们如何在这场演出中找准自己的位置呢？ | 「不是反问句」 |
| 3.4 | 如果无法坚持到底，又怎么会能够克服重重困难并取得成功呢？ | 「是反问句」 |

**答后讲解**：「哪里」「怎么」「何必」都带着答案。第三句的「如何……呢」是**真的在问**，作者接下来才回答，所以不是反问句。
